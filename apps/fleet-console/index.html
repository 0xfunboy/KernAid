        Open an incident case

        Choose an observed source, severity and optional operational queue. Evidence stays on the device; Fleet stores only signed state digests.

        Use an operational label, never a name or email address.

        Case workflow

        Update incident

        Digest-only relationship

        Link a work order

        Only typed orders for the case's source device are eligible. The case records state and result digests, never diagnostic evidence.

        Administrator-only finalization

        Close and seal case

        Fleet freezes linked work-order digests, creates canonical JSON and signs its report digest with the external service receipt key.

        Closure is immutable. Review the linked results before sealing this case.
